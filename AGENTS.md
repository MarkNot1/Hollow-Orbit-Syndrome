# Hollow Orbit Syndrome

- Prefer the shortest clear, robust solution with the least runtime work and unnecessary data duplication. Reuse existing assets and code where appropriate.
- Treat performance, memory use, and concise implementation as requirements. Avoid per-frame work, allocations, extra components, and abstractions unless the behavior needs them.
- Do not sacrifice correctness or maintainability for fewer lines. Verify the affected behavior; distinguish measured performance improvements from expected benefits.
